# Лабораторна робота №2: Розробка алгоритмів з розгалуженою структурою

Виконав: Шевченко Нікіта Вікторович, група ІСТ-21, варіант 17 (додатковий варіант: 17 + 5 = 22).

## Структура репозиторію

* v17.cpp — обчислення розгалуженої функції для варіанта 17
* v22.cpp — обчислення розгалуженої функції для варіанта 22
* region.cpp — перевірка попадання точки (x, y) у заштриховану область

## Компіляція та запуск

`bash
g++ v17.cpp -o v17 -lm
./v17

g++ v22.cpp -o v22 -lm
./v22

g++ region.cpp -o region -lm
./region
